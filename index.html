1. What is Arduino?

Arduino is a small electronic development board that can be programmed to control electronic components. Think of it as the brain of a project.

👀

Input

A sensor detects or receives information from the environment.

🧠

Process

Arduino follows the instructions in its program and decides what to do.

⚙️

Output

A motor, light, buzzer, or other device performs an action.

Everyday example: a person sees a ball (input), decides to catch it (process), and moves their hands (output). Arduino projects follow a similar pattern.

2. Our Project: Automatic Smart Dustbin

A Smart Dustbin opens its lid when a hand comes close to the sensor. After a short wait, the lid closes automatically. We do not need to touch the lid.

Project reference image: the electronic parts work together to make the dustbin lid move automatically.

Think about it: Where have you seen automatic doors, faucets, or lights? They use a similar idea: detect something, process the information, and respond.

3. Materials Needed

Study the pictures below so you can recognize the main electronic parts before assembling the project.

4. How Does It Work?

Detect: The ultrasonic sensor sends sound waves and listens for the echo from an object, such as a hand.
Measure: The sensor helps estimate how far away the hand is.
Decide: Arduino checks the measured distance against the value in its program.
Move: If the hand is close enough, Arduino commands the servo motor to open the lid.
Close: The program waits, then commands the servo to return the lid to its closed position.

Remember the three main roles

InputUltrasonic sensorDetects a nearby object and measures distance.
ProcessArduino UnoReads the measurement and follows the program.
OutputServo motorMoves the lid open or closed.

6. Basic Arduino Program

This sample opens the lid when an object is detected within 20 cm. It waits three seconds and then closes the lid.

#include <Servo.h>

// Create a servo motor object
Servo dustbinServo;

// Assign the sensor pins
const int trigPin = 9;
const int echoPin = 10;

// Assign the servo pin
const int servoPin = 6;

// Store the measured distance
long duration;
int distance;

void setup() {
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);

  dustbinServo.attach(servoPin);
  dustbinServo.write(0); // Start with lid closed

  Serial.begin(9600);
}

void loop() {
  // Send an ultrasonic signal
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  // Receive the reflected signal
  duration = pulseIn(echoPin, HIGH, 30000UL);

  // Convert the signal into centimeters
  if (duration == 0) {
    distance = 0; // No valid echo received
  } else {
    distance = duration * 0.034 / 2;
  }

  Serial.println(distance);

  // Open only when a valid distance is 20 cm or less
  if (distance > 0 && distance <= 20) {
    dustbinServo.write(90); // Open lid
    delay(3000);            // Wait 3 seconds
    dustbinServo.write(0);  // Close lid
  }

  delay(100);
}
What do the important code words mean?
  • pinMode() sets a pin as INPUT or OUTPUT.
  • digitalWrite() sends a HIGH or LOW signal.
  • pulseIn() measures how long a signal stays HIGH.
  • if checks whether a condition is true.
  • servo.write(90) tells the servo to move to a position of 90 degrees.
  • delay(3000) pauses the program for 3,000 milliseconds (3 seconds).
Servo adjustment: The 0° and 90° positions are starting examples. Adjust them to match the hinge and linkage of your actual lid. This simple program closes after three seconds even if a hand remains nearby.

How to upload the program

  1. Install and open Arduino IDE on the computer.
  2. Connect the Arduino Uno using a USB cable.
  3. Select Tools → Board → Arduino Uno.
  4. Select the correct USB port under Tools → Port.
  5. Paste the code and click Verify (✓).
  6. Click Upload (→), then test the sensor.

🎞️ Visual Presentation: How to Upload a Program to Arduino

Imagine that you are sending instructions from your computer to the brain of the Smart Dustbin. Follow one slide at a time.

Slide 1 • The big idea

What does “upload a program” mean?

Uploading means sending the instructions from the computer into the Arduino board. The Arduino then remembers those instructions and follows them when it has power.

  1. Computer: where we write the instructions.
  2. USB cable: the pathway that carries the program.
  3. Arduino Uno: receives and runs the program.
Think of it like sending a message to a friend: the computer sends the instructions, and Arduino receives the message.
Slide 2 • Prepare the computer

Open the Arduino IDE

Arduino IDE is the computer program where we type, check, and send our Arduino code. IDE means Integrated Development Environment.

  1. Turn on the computer.
  2. Find and open Arduino IDE.
  3. Open the Smart Dustbin program or paste the complete code into the editor.
  4. Look at the code before sending it to the board.
The code is also called a sketch in Arduino. A sketch is simply a program written for an Arduino board.
Slide 3 • Connect the board

Connect Arduino to the computer using USB

  1. Find the USB connector on the Arduino Uno.
  2. Connect the correct USB cable to the Arduino.
  3. Connect the other end to the computer.
  4. Check that the Arduino power light turns on.

The USB cable allows the computer and Arduino to communicate. It may also provide power to the board.

Important: Use a USB cable that can transfer data, not a charge-only cable. If the computer does not detect the board, ask your teacher to check the cable and USB port.
Slide 4 • Choose the correct board

Tell the IDE which Arduino board you are using

The computer must know the exact type of Arduino board so it can prepare the program correctly.

  1. On the menu, click Tools.
  2. Choose Board.
  3. Choose Arduino AVR Boards, if shown.
  4. Click Arduino Uno.

In Arduino IDE 2, you may also use the board selector near the top of the window. The layout can look a little different depending on the IDE version.

For this lesson, our board is Arduino Uno. Do not select Arduino Nano, Mega, or another board by mistake.
Slide 5 • Choose the USB port

Select the port connected to your Arduino

A port is the computer's connection number for the USB device. On Windows, it often appears as COM3, COM4, or another COM number.

  1. Click Tools.
  2. Choose Port.
  3. Look for the port that appears when your Arduino is connected.
  4. Select that port, for example COM3 (Arduino Uno).
Your COM number may be different. If no port appears, check the USB data cable, reconnect the board, and ask your teacher for help. Do not guess the port.
Slide 6 • Check before sending

Click Verify first (✓)

Verify asks the IDE to check and prepare your code. It looks for programming mistakes and converts the sketch into a form the Arduino can understand.

  1. Click the checkmark (✓) button.
  2. Wait while the IDE checks the code.
  3. If it says compilation is complete or shows a successful result, continue.
  4. If red error messages appear, stop and ask your teacher to help correct them.
Remember: Verify checks the program. It does not send the program to the Arduino yet.
Slide 7 • Send the program

Click Upload (→) and wait for success

  1. Click the right-arrow (→) Upload button.
  2. The IDE checks the code again and sends it through the USB cable.
  3. Wait. Do not unplug the USB cable while uploading.
  4. Look for a message such as Done uploading.
  5. Now Arduino can run the uploaded program.
What happens next? The Arduino follows the instructions: the ultrasonic sensor detects a nearby hand, and the servo motor moves the dustbin lid. Ask your teacher to check the circuit and power before testing.
Slide 8 • Observe and test

Test the Smart Dustbin with your teacher

  1. Keep hands clear of moving parts while checking the lid.
  2. Ask your teacher to confirm the wiring and safe power supply.
  3. Move your hand near the ultrasonic sensor.
  4. Observe whether the servo opens the lid.
  5. Wait and observe whether the lid closes.

If it does not work, do not pull wires while the circuit is powered. Turn off or disconnect power with teacher supervision, then check the wiring, code, board, and port.

You did it! You have learned the basic journey: WRITE → CONNECT → SELECT BOARD → SELECT PORT → VERIFY → UPLOAD → TEST.

9. Teacher Guide: Synchronize Assessment Results to Google Sheets

Follow these steps to create a Google Sheet that collects each student's name, section, score, date, and selected answers.

Part A — Create the Google Sheet

  1. Sign in to the Google account that will own the assessment records.
  2. Open Google Sheets and create a blank spreadsheet.
  3. Give it a title, such as Arduino Smart Dustbin Assessment Results.
  4. Choose Extensions → Apps Script.

Part B — Add the Apps Script

Delete the sample code in the Apps Script editor and paste the following code. Change the spreadsheet ID only if you are using a different spreadsheet.

const SHEET_NAME = "Responses";

function doPost(e) {
  try {
    const data = JSON.parse(e.postData.contents);

    const ss = SpreadsheetApp.getActiveSpreadsheet();
    let sheet = ss.getSheetByName(SHEET_NAME);

    if (!sheet) {
      sheet = ss.insertSheet(SHEET_NAME);
    }

    if (sheet.getLastRow() === 0) {
      sheet.appendRow([
        "Timestamp",
        "Student Name",
        "Grade and Section",
        "Assessment Date",
        "Score",
        "Total Items",
        "Answers (JSON)"
      ]);
    }

    // Basic server-side validation
    if (!data.name || !data.section || !Array.isArray(data.answers)) {
      throw new Error("Missing required student or answer information.");
    }

    sheet.appendRow([
      new Date(),
      String(data.name).slice(0, 120),
      String(data.section).slice(0, 80),
      String(data.assessmentDate || ""),
      Number(data.score) || 0,
      Number(data.total) || 15,
      JSON.stringify(data.answers)
    ]);

    return ContentService
      .createTextOutput(JSON.stringify({ success: true }))
      .setMimeType(ContentService.MimeType.JSON);

  } catch (error) {
    return ContentService
      .createTextOutput(JSON.stringify({
        success: false,
        message: error.message
      }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

Part C — Deploy the Apps Script as a Web App

  1. Click Deploy → New deployment.
  2. Click the gear icon and choose Web app.
  3. For Execute as, select Me.
  4. For Who has access, select the access option permitted by your school's Google Workspace and privacy rules. If using a public-access option, understand that anyone who obtains the URL may send data to the sheet.
  5. Click Deploy and authorize the requested permissions.
  6. Copy the Web App URL ending in /exec.

Part D — Connect the Web App to this lesson page

  1. Return to this HTML file in a text editor.
  2. Find const GOOGLE_SCRIPT_URL = ""; near the bottom of the JavaScript.
  3. Paste your Apps Script Web App URL between the quotation marks.
  4. Save the HTML file, then upload or host the updated file again.
  5. Submit one test assessment and check whether a new row appears in the Responses tab.
Important technical note: This page sends the result using a browser-compatible no-cors request. The browser cannot read the Apps Script response, so the page can report that the request was sent, but it cannot prove that the row was saved. Always verify the test row in Google Sheets. If the URL or deployment changes, update the URL in the HTML or save the new URL in the browser.

Privacy and assessment security

  • Collect only the student information needed for class assessment.
  • Limit access to the spreadsheet to authorized school personnel.
  • Follow your school's data privacy and records-retention policies.
  • The access code in a standalone HTML file is a classroom gate, not strong security. A technically skilled student can inspect the source code and find it. For stronger control, use a teacher-controlled server-side check or a private learning platform.
  • The sample Apps Script accepts incoming submissions and does not independently verify the quiz score or access code. Do not treat the sheet as tamper-proof exam evidence.

🌟 Lesson Takeaway

Arduino projects turn ideas into actions. In our Smart Dustbin, the sensor detects a nearby hand, Arduino processes the distance, and the servo motor moves the lid.

Remember: INPUT → PROCESS → OUTPUT. You do not have to be an expert programmer to begin inventing. Start with a simple idea, learn the parts, connect them safely, write instructions, and test your project.
